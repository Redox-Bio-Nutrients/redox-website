# WebAnalysis

A product's guaranteed analysis: label and value rows joined by a dotted leader in the product colour, inside one cream slab.

Static rendition hand-written from redox-website/src/components/products/sections/AnalysisSection.astro.

- `web-bg-surface` slab, `web-radius-3xl`, 48px padding (24px on phones), at most 1024px wide.
- Rows have no rules between them; the 2px dotted leader in the product colour (else `web-green`) does the joining. Labels medium, values semibold tabular, both `web-lead`.
- Heading in `web-display-sm` serif above it.
