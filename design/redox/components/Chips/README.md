# Chips

Toggle chips for picking several values from a short list (categories, roles, regions).

Static rendition hand-written from apps/web/src/components/ui.tsx (`Chips`).

- Off: `color-line` border. On: `color-signal` fill, `color-signal-ink` text, ink border. Small leaf corner, 14px text.
- Each chip is a real checkbox (visually hidden), so keyboard focus shows the ink ring on the chip.
- Over 12 options, add a filter input above.
