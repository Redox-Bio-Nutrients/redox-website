# EmptyState

What a list says when it's empty: a line drawing, what's missing and what to do next.

Static rendition hand-written from apps/web/src/components/Moments.tsx (`EmptyState`).

- A 48px line drawing in `color-muted` (sprout, people, mail, form, calm sun; 1.6px stroke, round caps), a `body-strong` title and a muted sentence, then an optional action.
- `compact` inside a card or table row: smaller and left-aligned.
- Replaces bare "Nothing yet" lines everywhere.
